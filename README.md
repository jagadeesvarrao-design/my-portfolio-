# 💻 AI, Python & Data Specialist - Personal Portfolio

A sleek, responsive, and recruiter-friendly personal portfolio website designed with a **premium dark neon theme** and smooth micro-interactions. Tailored to represent skills in **Python Scripting, AI Prompt Engineering, Data Analytics, and SQL database systems**.

## ✨ Features & Upgrades

- **Premium Visual Theme**: Deep, modern `#030712` canvas utilizing a three-color neon gradient highlight (`Blue` ➔ `Purple` ➔ `Pink`) and customized system scrollbars.
- **Dynamic Subtitle Typewriter**: native JavaScript typing animation highlighting specialized roles.
- **Ambient Cursor Trail**: An interactive follower trail circle that smoothly tracks mouse coordinates and reacts dynamically to clickable targets.
- **Scroll Progress Tracker**: A visual horizontal bar at the top of the viewport indicating the user's scroll progression.
- **Recruiter Scannable layout**:
  - **Quick Stats Bar**: A 2-column details card on the *About Me* section showing immediate profile insights.
  - **Mini Technology Badges**: Organically organized skill sets grouped into Python, AI, Data, and SQL categories.
  - **Credentials Panel**: A dedicated grid card next to education to highlight certifications and academic milestones.
- **Particles Background**: Elegant drifting particles powered by lightweight `particles.js`.

## 🚀 Local Setup & Development

To open the project locally, you don't need any complex frameworks or build dependencies. Simply clone the repository and run:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/jagadeesvarrao-design/portfolio.git
   ```
2. **Open index.html**:
   Double click the `index.html` file or run it via a local static server extension in your editor (e.g., Live Server in VS Code).
